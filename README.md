# Deep Reinforcement Learning for Mapless Robotic Navigation under Dynamic Occupancy Constraints

The repository contains the GridWorld environment, the training and evaluation protocol, the 28 trained models of the main comparison (A2C, PPO, DQN, and Double DQN, seven seeds each), and scripts that reproduce every table and result figure of the paper from the released data.

## Overview

The task is mapless navigation on a 20x20 grid: the agent must reach a goal from a random start using only a compact egocentric observation, without access to the global obstacle map. Static obstacles are fixed per episode; dynamic obstacles act as **mobile occupancy constraints**. They block cells temporarily but never cause terminal collisions, so failures occur only by truncation (500 steps).

| Component | Description |
|---|---|
| Grid | 20x20, 50 static and 10 dynamic obstacles (about 15% occupancy) |
| Actions | Discrete(3): turn left, move forward, turn right |
| Observation | 11-D: five free-distance readings (front, left, right, front-left, front-right), goal displacement (dx, dy) in the global frame, one-hot heading |
| Dynamic obstacles | Each step, the options {stay, N, S, W, E} are visited in random order and the first valid one is executed; empirical stay probability of about 0.23 (`scripts/dynamic_obstacle_stats.py`) |
| Episode length | 500 steps (truncation) |

Reward function:

| Term | Value | Description |
|---|---|---|
| r_p | -0.02 | Step penalty |
| r_g | -0.005 | Turn penalty |
| r_delta_d | 0.25 (d_{t-1} - d_t) | Progress toward the goal (Manhattan distance) |
| r_f | 0.03 d_front | Frontal free space |
| r_b | -1.5 | Attempt to move into a blocked cell |
| r_goal | +5.0 | Goal reached |

## Repository structure

```
gridnav/                 Python package
  env.py                 RobotGridWorldEnv and reward configurations
  algorithms.py          Default hyperparameters, Double DQN implementation, model builder
  evaluation.py          Deterministic evaluation and training callback
  fixed_maps.py          The three structured maps used for transfer evaluation
scripts/
  train.py               Train one algorithm for one or more seeds
  evaluate.py            Evaluate saved models on the 50 fixed evaluation episodes
  evaluate_fixed_maps.py Transfer evaluation on the structured maps
  analyze.py             Reproduce all statistics and tables of the paper
  make_figures.py        Reproduce the result figures
  dynamic_obstacle_stats.py
                         Empirical stay probability of the dynamic obstacles
models/
  main/                  A2C, PPO, DQN, seeds 0-6 (main comparison)
  ddqn/                  Double DQN, seeds 0-6
results/
  main/                  Per-seed final metrics, learning curves, and run times
  ddqn/                  Per-seed final metrics and learning curves of Double DQN
  fixed_maps/            Per-seed success rates on the structured maps
  reward_sensitivity/    Per-seed success rates of the reward-sensitivity study
  hyperparameter_search/ Per-seed success rates of the hyperparameter search
figures/                 Figures generated by scripts/make_figures.py
tests/                   Unit tests and a reproduction test of the released models
```

## Installation

Python 3.10 or newer is required.

```bash
git clone https://github.com/brimi04/DRL-for-Mapless-Robotic-Navigation-under-Dynamic-Occupancy-Constraints.git
cd DRL-for-Mapless-Robotic-Navigation-under-Dynamic-Occupancy-Constraints
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Quick start

Reproduce all tables of the paper from the released results (a few seconds):

```bash
python scripts/analyze.py
```

Regenerate the result figures:

```bash
python scripts/make_figures.py
```

Evaluate the released models and check that they reproduce the released results:

```bash
python scripts/evaluate.py --models-dir models/main --algos A2C PPO DQN --out eval_main.csv
python scripts/evaluate.py --models-dir models/ddqn --algos DDQN --out eval_ddqn.csv
python scripts/evaluate_fixed_maps.py --models-dir models/main --out fixed_maps.csv
python -m pytest tests
```

## Reproducing the experiments

All runs use 1,000,000 timesteps, a periodic deterministic evaluation every 20,000 steps on 20 fixed episodes, and a final evaluation on 50 fixed episodes (seeds 2000-2049). Hyperparameters are defined in `gridnav/algorithms.py`.

| Experiment | Command |
|---|---|
| Main comparison | `python scripts/train.py --algo A2C --seeds 0 1 2 3 4 5 6 --outdir runs/main` (repeat for `PPO` and `DQN`) |
| Double DQN | `python scripts/train.py --algo DDQN --seeds 0 1 2 3 4 5 6 --outdir runs/ddqn` |
| Reward sensitivity | `python scripts/train.py --algo PPO --seeds 0 1 2 --reward-config no_rdelta --outdir runs/reward` (configurations: `baseline`, `no_rf`, `no_rdelta`, `low_rdelta`, `high_rdelta`, `no_rp`) |
| Hyperparameter search | `python scripts/train.py --algo A2C --seeds 0 1 2 --override '{"n_steps": 80, "learning_rate": 0.001}' --outdir runs/hparam` |
| Transfer to fixed maps | `python scripts/evaluate_fixed_maps.py --models-dir runs/main` |

Hyperparameter search grid: A2C, full grid over `n_steps` in {20, 80, 128} and learning rate in {3e-4, 7e-4, 1e-3} (nine configurations); PPO, learning rate in {1e-4, 3e-4, 7e-4} and clipping range in {0.1, 0.2, 0.3} varied one at a time around the defaults (five configurations); DQN was not tuned.

Computational cost (CPU only, two threads): about 21 min per run for A2C and DQN and about 29 min for PPO. The main comparison (21 runs) takes about 8.3 hours; independent runs can be executed in parallel as separate processes.

## Main results

Final performance over seven seeds (mean ± sample standard deviation; 50 evaluation episodes per seed):

| Metric | A2C | PPO | DQN | DDQN |
|---|---|---|---|---|
| Success rate | 0.814 ± 0.056 | 0.863 ± 0.021 | **0.931 ± 0.040** | 0.931 ± 0.020 |
| Mean reward | 2.219 ± 4.963 | 4.757 ± 0.430 | **6.249 ± 0.667** | 6.222 ± 0.311 |
| Mean steps | 123.1 ± 28.1 | 97.0 ± 11.0 | **59.3 ± 19.5** | 58.0 ± 9.8 |
| Convergence (steps) | 371,429 | 420,000 | **25,714** | 31,429 |

Kruskal-Wallis tests indicate significant differences among A2C, PPO, and DQN (p < 0.002 for success rate, mean reward, and mean steps). DQN differs significantly from A2C and PPO (Mann-Whitney U with Bonferroni correction), whereas DDQN does not differ significantly from DQN (p = 0.644). `scripts/analyze.py` prints all values reported in the paper.

## Notes on reproducibility

- **Evaluation is deterministic.** Evaluation episodes are reset with explicit seeds, and the released models reproduce the released per-seed results exactly (`tests/test_reproduce_results.py`).
- **Training maps are not seeded.** As in the experiments of the paper, `reset()` without a seed draws a new random map from fresh entropy; the seed `s` only initializes the network weights and the learning algorithm (`stable_baselines3.common.utils.set_random_seed`). Retraining therefore produces statistically consistent but not bit-identical results.
- **Double DQN.** Stable-Baselines3 does not provide Double DQN. `gridnav.algorithms.DoubleDQN` overrides only the TD target of the Stable-Baselines3 DQN update: the online network selects the next action and the target network evaluates it.
- **Reward sensitivity and hyperparameter search.** Only per-seed success rates are released for these studies (models were not archived). In `results/reward_sensitivity/per_seed_success.csv`, one value (PPO, `low_rdelta`, seed 0) is missing from the experiment log and was reconstructed from the reported configuration mean; it is flagged in the `note` column.
- **Fixed maps.** `gridnav/fixed_maps.py` contains the exact maps used for the transfer evaluation. Map3 results are highly sensitive to its geometry, so modifying the map changes the results substantially.
- **Software versions.** The experiments were run on Google Colab (CPU). The released results were verified with the versions in `requirements.txt`.
